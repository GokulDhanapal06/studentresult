# Student Result Portal

## Description

This is a Student Result Portal developed using VBScript.

The program collects the student's:
- Register Number
- Date of Birth

It then validates the register number, calculates the marks, total, and displays the examination result.

## Technology Used

- VBScript
- Windows Script Host (WSH)

## Features

- Register Number validation
- Date of Birth input
- Subject-wise marks
- Total marks calculation
- Pass/Fail result
- Student result display

## How to Run

1. Download the `studentresult.vbs` file.
2. Open it on a Windows computer.
3. Double-click the `.vbs` file to run the program.
4. Enter the required details when prompted.

## File

`studentresult.vbs` – Main VBScript program.
